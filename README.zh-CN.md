# DSH 构建密闭性证据

作者 / 维护者：He Fangsheng (贺方升 / 贺去病; also known as Dosen)· [hequbing.com](https://www.hequbing.com)

这是 DeepSeek Harness 供应链的离线、确定性证据层。它只核验一份显式、纯哈希的构建访问回执，判断文件、环境变量、网络、时钟、随机源和输出是否都落在声明闭包内。

它不执行构建、不实施沙箱、不认证回执，也不能证明没有漏记访问；`hermetic` 仅表示输入回执内部完整并符合策略。它同样不证明可复现性：`dsh-reproducible-build-proof` 比较独立重建是否产出逐字节相同结果；本插件只核验单次构建记录的外部影响闭包。

已观察到的未声明访问会失败；被拒绝的未声明尝试作为隔离证据保留，但不破坏闭包。v1 网络策略只支持 deny，任何实际网络访问都会失败。声明的输入和输出必须全部被观察到，源码 revision、调用参数、时钟、随机种子和允许的环境变量值都用 SHA-256 绑定。

输入只接受工作区内的非符号链接 JSON 清单，原始日志、正文和秘密形态字段会被拒绝。DSH 写盘工具只写显式 `artifactDir`，生成内容寻址报告，并执行独占创建与回读校验。
